# Лабораторная работа №6 — GitHub Actions

Учебный проект по автоматизации CI/CD.

## Workflow

- `hello-world.yml` — вывод приветствия при push в `main`.
- `sys-info.yml` — системные параметры Ubuntu и переменные GitHub.
- `script-runner.yml` — запуск `scripts/build.sh` и вывод `build_info.txt`.
- `matrix-test.yml` — проверка на Ubuntu, macOS и Windows.
- `pr-check.yml` — проверка README при создании Pull Request и обработка сбоя.
