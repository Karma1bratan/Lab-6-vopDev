## Цель работы
Познакомиться с Docker, загрузкой образов из Docker Hub, запуском контейнеров и созданием собственного образа с помощью Dockerfile.

## 1. Контейнеры и виртуальные машины

- **Виртуальная машина (VM)** запускает собственную операционную систему и обычно требует больше ресурсов и места на диске.
- **Контейнер Docker** использует ядро хостовой ОС, изолирует приложение и его зависимости, быстро запускается и обычно занимает меньше места.
- Виртуальные машины обеспечивают изоляцию на уровне системы, а контейнеры — на уровне процессов.

## 2. Проверка установки Docker

В терминале выполните:

```bash
docker --version
docker info
```

Если Docker установлен и запущен, команды покажут версию и информацию о среде.

## 3. Загрузка и запуск образа Python

```bash
docker pull python
docker run -it --rm python bash
```

Внутри контейнера проверьте Python:

```bash
python --version
exit
```

## 4. Создание собственного образа

В этой папке находятся `Dockerfile` и `app.py`. В каталоге `lab7-docker` выполните:

```bash
docker build -t lab7-python .
docker run --rm lab7-python
```

Ожидаемый вывод приложения: `Hello from Docker!` и версия Python.

## 5. Дополнительное задание: Nginx

```bash
docker run -d -p 8080:80 --name my-nginx nginx
```

Откройте в браузере [http://localhost:8080](http://localhost:8080). Должна отображаться стартовая страница Nginx.

Остановить и удалить контейнер после проверки:

```bash
docker stop my-nginx
docker rm my-nginx
```
