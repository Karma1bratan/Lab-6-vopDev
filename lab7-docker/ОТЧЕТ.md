## 2. Теоретическая часть

Docker — платформа контейнеризации, позволяющая упаковывать приложение и необходимые зависимости в изолированную среду. Образ — шаблон для запуска приложения, контейнер — запущенный экземпляр образа. Docker Hub — онлайн-репозиторий готовых образов, например Python и Nginx.

| Критерий | Виртуальная машина (VM) | Контейнер Docker |
|---|---|---|
| ОС | Обычно включает собственную гостевую ОС | Использует ядро хостовой ОС |
| Ресурсы | Обычно требует больше памяти и дискового места | Обычно легче и экономнее |
| Запуск | Как правило, медленнее | Как правило, быстрее |
| Изоляция | На уровне виртуализированной системы | На уровне процессов и окружения |
| Переносимость | Зависит от гипервизора и конфигурации | Образ можно переносить между совместимыми средами |

## 3. Проверка установки Docker

```bash
docker --version
docker info --format 'Docker server: {{.ServerVersion}}; OS: {{.OperatingSystem}}'
```

Обе команды успешно выполнены в среде Ubuntu на удалённом исполнителе GitHub Actions.

## 4. Загрузка и запуск Python из Docker Hub

```bash
docker pull python
docker run -it --rm python bash
```

Для автоматической проверки оболочка была запущена без интерактивного ввода:

```bash
docker run --rm python bash -lc 'echo "Container shell started"; python --version; echo "Bash container test passed"'
```

Результат: образ Python успешно загружен; Bash и Python внутри контейнера запустились; проверка завершилась успешно. В интерактивном терминале после запуска можно выполнить `python --version`, затем `exit`.

## 5. Создание собственного образа

В каталоге `lab7-docker` созданы файлы `Dockerfile` и `app.py`.

**Dockerfile:**

```dockerfile
FROM python:3.12-slim

WORKDIR /app
COPY app.py .

CMD ["python", "app.py"]
```

**app.py:**

```python
import platform
import sys

print("Hello from Docker!")
print(f"Python version: {platform.python_version()}")
print(f"Executable: {sys.executable}")
```

Сборка и запуск:

```bash
docker build -t lab7-python .
docker run --rm lab7-python
```

Фактический вывод успешного запуска:

```text
Hello from Docker!
Python version: 3.12.15
Executable: /usr/local/bin/python
```
